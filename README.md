# Portfolio Scroll Design

A professional portfolio website showcasing projects and skills. Built with React, TypeScript, TanStack Start, and Tailwind CSS.

## Features

- Single-page scrolling design
- Smooth animations with Framer Motion
- Responsive UI components built with Radix UI
- Modern styling with Tailwind CSS

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
